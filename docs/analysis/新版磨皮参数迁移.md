## 实施与兼容

本项目继续使用自研 Vision 几何蒙版与 Core Image 管线。新的平滑支持蒙版通过现有未保护/已保护覆盖率恢复五官衰减比例，再对非肤色区域扩展；两个控制独立于曝光/肤色蒙版。默认 100%/100% 直接沿用原覆盖路径。微细锐化在局部支持区域恢复亮度细节与少量色彩细节，可在磨皮量为零时独立使用。

原目标的语义蒙版、特征形状、纹理处理和复杂组合尚未全链对齐，因此本次是参数含义、连续控制和对应局部处理的迁移，不表示整个新版已逐像素复刻。旧版全局磨皮/全局锐化仍可通过更多设置使用，不与新保护项偷换含义；历史工程保留原强度。

PGBeautySettings v2 尾部增加三个 float，保留 v1 的 160 字节前缀。解码只接受 v1+160 字节或 v2+新完整长度；旧状态补中性默认值。PGInspectorState 仍使用 schema 1 数值字典，旧 bool 30 迁移到缺失的 75，新数值存在时优先采用新值。面板提交先保存权威对象 210，成功后再镜像旧 bool；每次拖动步进仍使用独立宿主 action。
