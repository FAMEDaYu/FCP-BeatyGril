## 已实现的功能

- 中频磨皮、强度、半径、高频细节平滑、锐化、五官保护及各大功能分组开关。
- 肤色提亮、色相、饱和度、均匀肤色；原色及自然白、冷白、暖白、红润白、小麦、古铜六个程序化风格。
- 牙齿美白和眼睛提亮，基于 Vision 面部区域构建软蒙版。
- 瘦脸、大眼、短脸、窄脸、下巴、V 脸、下颌、颧骨、小头和小头范围。
- 全脸/选中脸、画面点击选脸、多人高速检测、防跳脸范围、脸框和跟踪框。
- 三个独立跟踪目标，向前/向后分析，清除当前目标；精确 CMTime 数据持久化到宿主工程，可逆序和任意顺序读取。
- 蒙版阈值/柔度/边缘保护、皮肤/牙齿/眼睛通道预览与反转、包含几何变形的整体混合。
- 保留透明度、完整输入范围、非零图像原点与宿主上下原点；原生 FxPlug 参数可由宿主保存和制作关键帧。

## 复刻边界

本交付为功能相近的独立实现，算法结果存在以下差异：

1. 原版六个肤色 LUT 由独立颜色变换替代，风格名称接近，颜色值不相同。
2. 原版人脸网格/曲线位移采用本项目的平滑椭圆采样位移替代。各脸型权重和曲线、眼嘴软蒙版由本项目编写。
3. 皮肤支持区域使用 Vision 面部区域及独立的肤色/高通备用蒙版；原版完整皮肤分割、时间稳定和细部 mask 尚未等价恢复。
4. 本版最多保存三个独立目标、每次最多处理十六张脸。原版存在动态目标列表与旧版三目标字段，本次未完整恢复动态列表上限及全部分页操作。
5. 本版逐帧 Vision 分析并保存几何数据，渲染仅读取记录；原版 OpenCV 光流与时间稳定策略没有照搬。真实运动、多人交叉、遮挡、快速切镜的身份保持尚需专项对照。
6. 界面使用宿主的分组滑块与开关；原版卡片面板的布局没有照搬。眼睛提亮在本版可用，所分析原版主链实际将该项输入设为零。

跟踪数据每目标保存上限为 64 MB；超过上限时保留此前已保存的数据并报告错误。长素材应分段分析。仅实际验证通过的内容计入完成；本说明中的未知项不因编译或离屏测试通过而自动消除。
