# 大鱼人像美化 1.0.4 验证记录

日期：2026-10-21。环境：Apple Silicon M1 Max，macOS27.2、Motion6.4、Final Cut Pro12.4、Xcode27.1、FxPlug SDK4.3.4、PluginManager1.7.4。Release包含arm64和x86_64；原生宿主实测为arm64，未在Intel机器实测。

## 用户报告的两个问题

FCP黑屏来自初版效果模板的输入链：Source Media=0且无clip/footage。已恢复标准Effect Source→clip→footage→本地Drop Zone.tiff。新模板在FCP的独立验收项目中成功替换为实际片段，并能调整美化参数；不能把此前XML通过当作原生输入链通过。

肤色提亮出现眼、鼻、唇周围圆洞，原因是调色复用了为磨皮扣除五官的蒙版。现在磨皮保留五官保护，肤色改用连续的人脸覆盖与柔和肤色分类，并羽化过渡、抑制蓝发溢色。提供的实际素材以75%提亮/50%中频在Motion复测，首帧及转头后画面未再见原圆洞；离线同帧旧/新算法对照保存在本机build目录，未将用户素材或截图上传源码仓库。强提亮仍会放大原素材的日光与阴影差异，不等于自动重布光。

## 宿主测试范围

FCP：使用用户给定的3840×2160、25fps蓝发人像视频。新建独立验收事件与10秒项目“ 大鱼人像美化验收-20261021 ”，位于当前已打开的素材库中，未修改原生产时间线；前5秒原片、后5秒同一段原片加效果。实际看到正常输入、非黑画面和提亮变化。勾选选脸并执行向前分析后，使用跟踪数据由0变为1，按钮路由与基本分析完成可用；未将其描述为125帧逐帧核验或复杂遮挡恢复通过。

Motion：独立普通视频项目，源PTS0、1920×1080/25fps/10秒，媒体通过本机链接引用给定视频；开启50%中频、75%提亮与人脸框。切换滤镜启用、从第1帧播放到第179帧均正常出图，人脸框随画面位置更新；选中滤镜可正常建立OSC连接。此QA工程依赖外置卷原视频，不作为可移植产品资源交付。

选脸控件：原生验收额外发现OBJECT坐标被二次归一化，十字落在画面角落；现直接使用归一化OBJECT坐标转换至CANVAS像素。Motion点参数桥接会归一化读取，却按中心像素写入，新增事件内读回检测及兼容转换，并校验最终位置；不依赖宿主版本号猜测。98项OSC测试同时覆盖文档约定与Motion像素桥接。事件现显式使用CANVAS坐标并由宿主转换回OBJECT，避免OBJECT鼠标事件的单位歧义。1.0.4的显式选脸点击回写尚未完成原生复测；界面被用户接管自测，已按要求停止自动化操作。98项离屏OSC/ASan检查不能替代这项原生验收。公开坐标依据：[Apple Creating Onscreen Controls](https://developer.apple.com/library/archive/documentation/AppleApplications/Conceptual/FXPlug_overview/OnScreenControls/OnScreenControls.html)。

宿主在更新前退出，新正式版安装后重新打开。曾在旧XPC连接未释放、临时构建插件仍被注册的热替换环境出现宿主关闭挂起/OSC连接崩溃；交付流程已增加宿主关闭检查，并在原生验收前注销构建目录的插件。没有把该崩溃直接归因为某条提亮公式。

## 功能边界与原版跟踪选项

用户给出的MS超级美颜V2.moef共发布15个入口，没有跟踪、前向或后向分析控件。没有额外分析按钮不影响原版默认自动跟随；活跃render路径与Motion运行均已确认这一点。复刻版的三目标离线分析与持久化属于独立扩展，应与默认实时跟随分开理解。

六种肤色风格采用自写调色变换，脸型当前使用Vision脸框场与眼部点位置的近似反向采样；瘦脸本身没有使用下颌轮廓点。未复制原版私有LUT或算法资源。没有完成原版逐像素对齐、全部脸型强度主观比对、多人交叉遮挡、所有宿主版本及Intel硬件验收。源码层保存/恢复测试不代替两宿主所有工程关闭重开场景。

## 用户复测与瘦脸专项分析

用户反馈“跟踪没问题”，同时提供最大瘦脸与侧脸变形对照。记录为用户实测反馈，不扩张为显式OSC点击、两宿主复杂场景或全部脸型验收通过。

后续静态REA和Apple Metal AIR分析确认：原版瘦脸以17组轮廓到鼻部/瞳孔锚点的局部位移驱动，当前瘦脸按框水平对称变形，两者的方向、范围与强度模型不同。独立Vision76点离线探针在同一视频11个采样时刻均检出1脸76点，含明显侧脸；它只证明关键点仍可获得，不代替原版宿主输出对照。探针使用Wall/Wextra编译成功并完成采样，没有执行原版APP、替换安装版或操作Motion/FCP。

分析报告见 [脸型变形与转脸分析](analysis/脸型变形与转脸分析.md)。当前安装1.0.4的变形问题尚未修复，本轮的诊断代码/证据/文档不改变已安装产品。
