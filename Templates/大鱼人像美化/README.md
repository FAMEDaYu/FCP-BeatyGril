# 大鱼人像美化 FCP 效果模板

版本：1.1.0。滤镜 UUID：`FB14B0E6-59B2-4836-916F-CD0C559E9241`。需配套同版大鱼人像美化 FxPlug APP。

## 三卡片与自动跟随

FCP 发布列表仅保留作者、网站两个空绑定展示项，以及一个空名称的自定义面板入口 `./210`，共3项。面板内提供“磨皮、美白、瘦脸”三张卡片和“更多”附加设置。主体人脸由当前画面自动选择并实时跟随，无需手动前向/后向分析。多人模式、预览框、防跳脸与各项调节由插件自定义面板承载。

原有46个平铺功能入口已撤下。旧49个参数定义及六组路径仍保留供旧项目兼容，插件以 SDK 隐藏标记注册；旧手动分析按钮、跟踪目标/状态、选脸点和目标数据不再发布为界面入口。隐藏的目标数据60/61/62不删除。发布 OSC 初始为0；旧OSC类注册由插件保留。

## 默认与旧项目

模板首次应用时，旧原生“中频磨皮”仍保存 `default=0 / value=0.5`，即初始局部磨皮50%；直接添加裸插件时为0%。自定义 `PGInspectorState` 初始 `hasEdits=NO`，因此读取并保留旧原生参数，不会用面板归档中的默认0覆盖模板0.5或旧项目数值。面板经过编辑后由自定义状态持久保存调节值。此模板不预置任何人脸身份或跟踪记录。

## 自有状态归档

参数210使用本插件生成的 `PGInspectorState` 安全键控归档：内部 `Custom Data` 对象、外部 `BlindDataObject` 与 `DataIsLegacy=false`，再按已核对的Motion文本编码和长度封装。保存 `schema=1 / edited=false`，不使用原版私有数据、类名、品牌资源或空 `<dataValue>` 猜测初始化。默认和当前归档相同，可完整解码并往返核验。

该编码依据原生文件静态结构及独立Foundation归档检查；1.1.0自定义面板在Motion/FCP中的实际创建、显示、交互、撤销和关闭重开恢复仍待用户验收，不能以XML可解析或归档解码成功代替宿主加载通过。

## 输入、媒体与版权

输入链沿用已修复的标准 Effect Source（Type=3、Drop Zone=1）：Source Media→clip `510000006`→footage `510000007`→相对文件 `Drop Zone.tiff`。该占位图随模板附带，420128字节，SHA256 `a7f8e3a2a431dbb3ce9e777040bb55e701cfe9ab9632e8cbb10359732bc8692e`。没有外部素材、示例人像或新动画。

作者与网站仍是同一个Rig下的两个无受控参数菜单：“FCP 版本作者→／大鱼先森Media”和“更多模板浏览器访问→／dayu.media”。仅展示信息，不改变渲染。

建议安装位置：`~/Movies/Motion Templates.localized/Effects.localized/大鱼/大鱼人像美化/`。本轮不安装模板，不操作Motion/FCP，由主任务完成正式交付，用户自测原生面板。

## 验证边界与历史修复

`PARAMETERS.json`记录新旧参数和3条发布路径；`VALIDATION.json`分开记录结构/归档核验与当前宿主待验项。内容选择状态保持为空，效果源、clip/footage、占位资源和版权绑定结构均保留。

早期模板曾误删clip/footage、将Source Media设为0，用户在FCP实测黑屏；随后恢复完整标准输入链，历史版本已实际出图。该历史结果只支持输入链，不能证明新1.1.0自定义面板已加载。1.0.5加入76点17组局部瘦脸；1.0.6移除IOSurface重复翻转并修复下巴三组局部位移。旧未标记坐标空间的跟踪数据保留但不重放，自动回退实时跟随。

## 可复现的只读核验

在仓库根目录执行：

```sh
python3 scripts/inspector-template.py audit "Templates/大鱼人像美化/大鱼人像美化.moef"
```

脚本可提取内外归档并核验自有类、schema、初始状态、3条发布和媒体引用；`encode --inner <本插件生成的Custom Data归档> --text-output <输出文件>` 可重新包装文本值，不启动宿主。其结果明确保留宿主加载待验状态。
